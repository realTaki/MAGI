# ASP

Casper (`@eva-001.magi`) and the chat relay. Build from the repository root with `npm run build`, then run `node apps/eva/eva.mjs --role asp`. The address is `MAGI_ASP`, or `MAGI_ASP_HOST` and `MAGI_ASP_PORT`. ASP does not start other processes.

The process shape, the relay, and provider sync are in [docs/architecture.md](../../docs/architecture.md).
