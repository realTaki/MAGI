# ASP

Casper (`@eva-001.magi`) and the chat relay. Build from the repository root with `npm run build`, then run `node dist/asp.js` from this directory. The desktop app does that. ASP listens on `127.0.0.1:42069` and does not start other processes.

The process shape, the relay, and provider sync are in [docs/architecture.md](../../docs/architecture.md).
