
# 每日笔记 (Daily Note) 记录指令
*这些规则指导我如何在对话过程中实时捕获信息。*

## 记录重点

- 记录从用户处学到的信息：已完成的任务、发送的邮件、生成的报告。
- 记录待办状态：哪些事情还挂着，哪些需要后续跟进。
- 记录用户偏好：例如"用户喜欢用 bullet points"、"用户希望回复更简短"。
- 记录项目背景：捕获关于正在进行的项目的关键上下文，以便后续调取。

## 禁忌规则

- 不记录外部琐碎事实（如实时天气、新闻、即时股价），只记录与用户行为相关的动态。

## 执行时机

- 在完成一项有意义的任务后，或用户提供反馈/修正建议时，通过 `update_daily_note` 接口静默追加。
